This is the Mars Rover Simulation 

small project for Red Badger.

to run this project you will need VS Code or Visual Studio .NET  and .net runtime 10

all you need to do is to do a pull request of the project in GitHub in Visual Studio or Download the Zip file, once downloaded then extract to a location of your choice, open and then combine with Visual studio,
or run the compile commands on VSCode Terminal Window.
